# Large-Scale Government Audit & Error Detection System

## Overview

This project simulates a large-scale government financial audit system designed to detect high-risk transactions, budget variances, and financial exposure using machine learning and analytics engineering best practices.

The system processes 500,000+ simulated government transactions across:

- Procurement
- Payroll
- Benefits
- Inspections

The pipeline performs data cleaning, anomaly detection, budget variance analysis, and exports a Tableau-ready dataset for executive reporting.

---

## Key Features

- Large-scale financial data simulation (500,000+ records)
- Data validation & cleansing workflows
- Machine Learning anomaly detection (Isolation Forest)
- Budget vs. Actual Spend variance analysis (>20% deviation flag)
- Financial impact KPIs embedded in dataset
- Fiscal year filtering (2021–2025)
- Tableau-ready combined dataset (CSV + Excel)
- Reproducible Python project structure with virtual environment
